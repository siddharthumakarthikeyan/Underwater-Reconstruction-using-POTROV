Overview

POTROV is a custom remotely operated vehicle built by Potential Engineering, India, for underwater search and rescue, structural inspection and object detection. This software stack turns the vehicle into a mapping tool: the pilot flies the ROV manually, a USBL (ultra-short baseline) acoustic system localises it, and imaging sonar and video are fused into a 3-D reconstruction of the underwater structure while an object-detection module reports targets in real time.

The stack runs on ROS Noetic with CUDA acceleration and is delivered to POTROV operators as an update package with configuration files and setup scripts for integration, calibration and field updates.

  • USBL-referenced mapping. Vehicle pose from the USBL fix anchors each sonar sweep in a common frame, so structures can be reconstructed without visual features in turbid water.
  • 3-D structural reconstruction. An optimised, GPU-accelerated pipeline for high-resolution sonar capture and dense reconstruction.
  • Real-time object detection. Detections from sonar and the video feed give the operator immediate feedback and situational awareness.
  • Standard outputs. Maps export to PLY, OBJ and STL for inspection reports, CAD comparison and post-processing.
  • Field deployment. Configuration files and setup scripts for installation, calibration and updates on the vehicle computer.
